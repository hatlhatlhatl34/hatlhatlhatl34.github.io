Official TikTok Developer Application Login Kit + Content Posting API

Publishing automation for one creator's own TikTok account

Fort Clip Factory is a personal content automation tool built by an individual Fortnite Creative creator. It connects to TikTok exclusively through the official TikTok APIs to automatically publish the creator's own Fortnite gameplay clips to the creator's own, explicitly authorized TikTok account.

This website is the home page of the fort-clip-factory developer application and explains exactly what the app does, which permissions it requests, and how data is handled.

What this app does

1

Log in

The account owner authorizes the app once via TikTok Login Kit. We only receive a pseudonymous ID, display name, and avatar to recognize the connected account.

2

Upload

The app uploads the creator's finished short-form video file through the official Content Posting API.

3

Publish

The video is published to the owner's own TikTok account, and the app checks the publish status afterward.

Why each TikTok product is used

  • Login Kit - lets the account owner grant and revoke authorization securely through TikTok's own consent screen.
  • Content Posting API - the official, TikTok-sanctioned way to upload and publish video content to the authorized account.

What this app never does

  • No scraping of TikTok data or users
  • No posting to any account that did not authorize the app
  • No selling or sharing of any user data
  • No collection of any viewer or follower data

How the pipeline runs

The publishing pipeline runs as scheduled jobs on GitHub's automation infrastructure. Each finished video is posted to the owner's authorized TikTok account with the same file and title the owner publishes on the owner's other channels. The app operates a single creator account - its own owner's.
