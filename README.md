# hatlhatlhatl34.github.io

Website for the **Fort Clip Factory** TikTok developer application, served by GitHub Pages:

- `index.html` - app landing page (what the app does, permissions, data handling)
- `privacy.html` - privacy policy
- `terms.html` - terms of service
- `callback.html` - OAuth redirect target for TikTok Login Kit authorization
- `tiktoku*.txt` - TikTok Developers domain-verification signature file

This site contains no secrets; all credentials live in GitHub Actions Secrets.
