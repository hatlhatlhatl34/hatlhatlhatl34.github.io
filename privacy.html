Privacy Policy

Fort Clip Factory - TikTok developer application · Effective date: November 17, 2026

1. Who we are

Fort Clip Factory is a personal automation tool operated by an individual developer (the "creator"). It is not a company and does not sell anything. You can reach the operator through the GitHub profile at github.com/hatlhatlhatl34.

2. Data the app receives from TikTok

When the account owner authorizes the app through TikTok's Login Kit consent screen, TikTok provides:

  • A pseudonymous user identifier (open ID)
  • The account display name
  • The account avatar photo
  • OAuth access credentials: a short-lived access token (expires within 24 hours) and a refresh token

The app does not request or receive the account password, phone number, email address, birthday, or contact list.

3. Video content

The app uploads and publishes video files prepared by the creator's own production pipeline to the creator's own TikTok account. The app never handles videos belonging to any other user.

4. How data is used

  • The basic profile data is used only to recognize which account is connected.
  • The access credentials are used to upload and publish the creator's videos and to check publish status.
  • The refresh token keeps the connection alive without repeated consent screens, until the owner revokes the app.

5. Storage and security

Access credentials are stored as encrypted secrets inside GitHub's automation infrastructure and are never written into source code, never displayed, and never shared with any third party. Video files pass through short-lived automation storage and are discarded after publishing.

6. Third-party processing

  • TikTok - receives uploads, publish requests, and the basic profile data described above.
  • GitHub - hosts the automation jobs and this website.

No other third party receives any data. No data is sold, rented, or used for advertising.

7. This website

This website is a static page. It sets no cookies, runs no analytics, and collects no visitor data.

8. No audience data

The app does not collect any information about viewers, followers, or other TikTok users. It operates only on the owner's own account and the owner's own content.

9. Children's privacy

The app does not knowingly collect personal data from children. It only processes the account owner's own authorization and content. If you believe a child's data was involved in error, contact the operator through the GitHub profile above.

10. Retention and deletion

Data is retained only while the app stays authorized. To revoke access at any time: TikTok app → Settings → Privacy → Apps and services → remove "fort-clip-factory". Revocation immediately invalidates the app's credentials. To request deletion of any remaining data, contact the operator through the GitHub profile.

11. Your rights

You may revoke authorization at any time (see section 10), request a copy of data held, or request its deletion by contacting the operator through GitHub.

12. Changes to this policy

If this policy changes, the effective date above will be updated and the change will be noted on this page.
